# 발행 전 점검 체크리스트

글을 내보내기 전에 이 항목들을 확인한다. 처음에는 눈으로 확인하고, 반복되면 스크립트로 옮긴다.

## 구조

- [ ] `이런 분을 위한 글` / `읽고 나면 달라집니다` / 성공 기준 문장이 있는가
- [ ] 도입이 질문이나 공감으로 시작하는가 (개념 정의로 바로 들어가지 않았는가)
- [ ] `정리하면` / `오늘 바로 할 수 있는 것` 으로 마무리했는가
- [ ] 큰 섹션 사이에 구분선(---)이 있는가

## 용어·서술

- [ ] 영어/전문 용어가 **처음 등장할 때** 풀이되어 있는가
- [ ] 핵심 개념에 비유가 최소 1개 있는가 (단, 남발하지 않았는가)
- [ ] 공식 사실과 내 해설이 구분되어 있는가
- [ ] 번역투("~되어집니다", "~에 의해")가 없는가
- [ ] 입문용이지만 "왜 그렇게 동작하는가" 원리가 남아 있는가

## 시각 장치

- [ ] 개념 비교는 표로 정리했는가
- [ ] 복붙용 예시만 코드블록에 넣었는가 (설명 문장을 코드블록에 넣지 않았는가)
- [ ] 코드 예시마다 결과 해석 한 줄이 붙어 있는가
- [ ] 나쁜 예/좋은 예 대비가 들어갔는가

## 기술 정확성

- [ ] 코드/명령어/설정이 실제로 동작하는가
- [ ] 버전·기본값(예: Java 21, Spring Boot, 포트, 기본 설정)이 맞는가
- [ ] 출처 링크가 해당 문장 가까이에 있는가 (끝에만 몰려 있지 않은가)

## 메타데이터 (블로그 발행 시)

- [ ] 제목에 검색 키워드 + 클릭 이유가 보이는가
- [ ] 한 줄 설명(description)이 있는가
- [ ] 태그가 있는가
